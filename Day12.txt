Today topic is Class B and Class A subnetting 

In the class B Address :
The leading bit is 10 
There is 16 bit in the network portion and 16 bit in the host portion of the network
The range for the network portion is 128 – 191
Example : 172.16.10.1
There are 2^14 = 16384 networks are present in class B network as 2 leading bits are reserved.
There are 2^16 = 65536 addresses per network is present in the class B network.

Borrowing one bit creates two subnets of the network.
Ex : 172.16.0.0 /16
In binary : - 
     172    .      16       .       0       .       0
   10101100 . 00010000 . 00000000 . 00000000
Now borrowing first bit from the host portion to the network portion.
No. of subnets 2^1 = 2.
No, of host usable address 2^15 - 2 = 32768-2 = 32766
Two subnets of the network are 172.16.0.0/17 and 172.16.128.0/17

In the class A Address :
The leading bit is 0
There is 8 bit in the network portion and 24 bit in the host portion of the network
The range for the network portion is 1 – 126 (0 & 127 are reserved)
Example : 10.0.0.0 /8
There are 2^7 = 128 networks are present in class A network as 1 leading bit is reserved.
There are 2^24 = 16777246 addresses per network is present in the class A network.

Borrowing one bit creates two subnets of the network.
Ex : 10.0.0.0 /8
In binary : - 
     10   .      0       .       0       .       0
00001010 . 00000000 . 00000000 . 00000000
Now borrowing first bit from the host portion to the network portion.
No. of subnets 2^1 = 2.
No, of host usable address 2^23 - 2 =  8388606
Two subnets of the network are 10.0.0.0/9 and 10.128.0.0/9
