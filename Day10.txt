IP addressing is a fundamental concept in networking where each device is assigned a unique identifier called an IP address 
(IPv4 is 32-bit, e.g., 192.168.1.1). 

Earlier, Classful Addressing divided IP addresses into fixed classes (A, B, C, D, E) with predefined network and host portions,
 but this led to inefficient use of addresses. To overcome this, Classless Addressing (CIDR) was introduced, which uses flexible
  prefix lengths like /25 or /26 to allocate IPs efficiently. 
  
IP addresses are also categorized as Public (globally unique and used on the internet) and Private (used within local networks, 
  such as 192.168.x.x, and require NAT for internet access).
  
Additionally, IPs can be Static (manually assigned and fixed, commonly used for servers) or Dynamic (automatically assigned by DHCP and 
can change over time). 

The Loopback Address (127.0.0.1) is used to test a device’s own network functionality, while APIPA (169.254.x.x) is automatically 
assigned when a DHCP server is unavailable, allowing only local communication without internet access.
